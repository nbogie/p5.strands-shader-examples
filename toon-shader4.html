Toon shader 4 — shininess-driven highlight

Same 4 bands as toon shader 3, but the highlight band's size is per-object. Set via shininess() alongside the material colours.

Inside the shader: step(0.5, pow(N·L, shininess)). For x < 1, pow(x, n) shrinks toward zero as n grows — so high shininess gives a pinprick, low shininess gives a broad patch.

The three shapes use shininess(80 / 15 / 3) so the difference is visible in one frame.

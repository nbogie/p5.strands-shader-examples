Normal viewer

Diagnostic shader: maps each pixel's surface normal directly to RGB. Each component goes from [-1,1] → [0,1] via n * 0.5 + 0.5.

The sphere shows a smooth gradient (every normal direction visible). The box shows 6 solid colours — one per face — because its normals are constant across each face.

Useful as a debugging tool: if the normal-viewer looks wrong on a mesh, all normal-based shaders (lighting, fresnel, breathe) will too.

Press any key to hide.

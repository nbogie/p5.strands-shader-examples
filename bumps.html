Bumps (procedural normal perturbation)

The surfaces look bumpy, but no extra geometry was added. The trick is to perturb each pixel's normal vector based on a noise field, then let the default Phong lighting compute the lit colour using the wobbly normals.

Three noise samples (at slightly offset positions) give independent x/y/z shifts. Add them into pixelInputs.normal, then call normalize() so the new direction is still a unit vector.

Frequency controls bump density; amplitude controls roughness. Try f = 8 for orange-peel, f = 40 for fine grit.

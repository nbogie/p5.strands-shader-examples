Outline 1 — minimal inverted-hull

Each shape is drawn twice: first scaled up ~10% as a dark hull with back-face culling so only the rear shell is visible, then again at normal size as a lit fill on top. The hull peeks out around the silhouette and reads as an outline.

One quirk: p5's projection matrix flips the y axis, which reverses triangle winding in clip space. So pass 1 culls BACK and pass 2 culls FRONT — opposite to most graphics tutorials.

The outline thickness is a fraction of object size, so it varies with distance. See outline 2 for a constant-pixel-width version.

Note: this sketch barely uses strands. The whole outline effect comes from CPU-side scale() + cullFace(); the strands material is just finalColor.set([0.2, 0.2, 0.2, 1]) — a constant dark grey. fill() would do the same job. See outline 2 for a version where strands actually pulls its weight (per-vertex normal push in cameraInputs for constant pixel width).

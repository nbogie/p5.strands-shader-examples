p5.strands shader sketches

Outline shaders

  • Outline shader 1
    Minimal inverted-hull outline (uniform scale + back-face cull).
  • Outline shader 2
    Constant pixel-width outline (depth-scaled normal push). Smooth-normal meshes only.
  • Outline shader 1 — applied
    Drifting building composites of stacked cubes; inverted-hull outline applied per part, with per-part palette colours.

Toon shaders

  • Toon shader 1
    3-band quantized diffuse using fill() only.
  • Toon shader 2
    3-band with separate shadow colour from ambientMaterial().
  • Toon shader 3
    4-band — adds a highlight from specularMaterial().
  • Toon shader 4
    4-band with per-object highlight size driven by shininess().

Lighting variants

  • Half-Lambert
    Softer diffuse: pow(N·L * 0.5 + 0.5, 2). Back-facing surfaces still get some light.
  • Fresnel (rim light)
    Bright glow at silhouettes via pow(1 - n.z, 3). Stylized rim highlight, no light setup needed.
  • Fresnel 2 — mouse-controlled
    Mouse-driven Fresnel rim: mouseX controls rim power (sharpness), mouseY controls intensity (brightness).
  • Hemisphere lighting
    Cheap "sky from above, ground from below" lighting — one-line mix based on normal.y.

Surface filters

  • Normal viewer
    Diagnostic — maps the surface normal directly to RGB. Useful sanity check before designing other normal-based shaders.
  • Bumps
    Procedural bump mapping — perturb each pixel's normal by 3D noise so default lighting paints in irregular surface detail without adding geometry.
  • Ripples
    Same idea as Bumps but with a regular sinusoidal pattern — looks like corduroy or a woven mesh.
  • Scanline (CRT)
    Old TV / arcade look — horizontal scan lines via fract on view-space y, green phosphor tint.
  • Heat haze
    Post-process buildFilterShader — samples the rendered canvas at a noise-displaced UV that scrolls upward over time. Silhouettes shimmer like rising desert air.

Vertex displacement

  • Wave
    Classic sin(t + x * freq) vertical wobble in world space — wave travels along the x axis across a row of spheres.
  • Breathe
    Push along world-space normal by sin(t) — inflate-and-deflate cycle. Smooth-normal meshes only.
  • Twist
    Rotates position.xz around the y axis by an angle proportional to y, oscillating over time. Spiral barber-pole effect on multi-ring primitives.
  • Jelly
    Noise-based vertex displacement — organic wobble using strands's built-in noise().
